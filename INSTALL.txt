Excuse Me, Drone 1.0.4 - 7 Days to Die 3.3 (release prepared; not yet published)

INSTALL / UPDATE
1. Close the game.
2. Back up the entire installed ExcuseMeDrone folder, including its DLL,
   ModInfo.xml and any customized Config/ExcuseMeDrone.cfg.
3. Replace the existing ExcuseMeDrone folder in your game's Mods folder
   with the ExcuseMeDrone folder from this archive. Do not keep two copies.
4. Restore your preferred settings in Config/ExcuseMeDrone.cfg.
5. Keep the game's bundled 0_TFP_Harmony mod installed.
6. Run the game with EAC disabled.

Default recall key: F10.
Change SummonKey in Config/ExcuseMeDrone.cfg and restart the game.

Follow mode: recall immediately at any distance, including with inventory open.
Stay mode: confirmation is required. OK switches to Follow before recall.
Cancel leaves the drone in Stay mode without moving it.
Broken drone recall does not repair the drone.

1.0.4 CANDIDATE SCOPE
This blocks all non-null drone revenge registrations through SetRevengeTarget,
including zombie/script sources, while allowing native null clears and non-drone calls.
Normal AI may still independently attack. Existing targets are not forcibly cleared.
No new damage, HP, movement or healing changes are introduced by this guard.
The maintainer reported test OK on 2026-10-17. This package reuses the supplied
v1.0.4 test-rebuild DLL without recompiling it. Earlier records report actual-v3.3
compilation and 51 controlled cases; these were not rerun for packaging.
The general report does not certify every scenario or dedicated/remote multiplayer.
Use single-player/local host; dedicated/remote installation remains unverified.
For rollback, close the game and restore the backed-up DLL, ModInfo.xml and config.
